# ✒️ Сценарист

Веб-версия приложения «Сценарист» — редактора сценариев.

## 📱 Использование на iPhone

Приложение полностью работает в браузере — устанавливать ничего не нужно.

### Добавить на экран «Домой»

1. Откройте ссылку в **Safari**
2. Нажмите кнопку **«Поделиться»** (квадрат со стрелкой вверх)
3. Выберите **«На экран „Домой"»**
4. Нажмите **«Добавить»**

После этого иконка появится на главном экране, и приложение будет открываться как обычное — на весь экран, без адресной строки.

## ✨ Возможности

- Редактор с быстрой вставкой элементов сценария
- Режим превью в формате кино
- Живая статистика: слова, страницы, сцены
- Помодоро-таймер
- Режим фокуса
- Экспорт в .txt и .fdx
- Встроенный справочник с туториалами и советами
- Работает офлайн
- Все сценарии хранятся только на устройстве
